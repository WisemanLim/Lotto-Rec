# 시나리오 — impl 44th: 'seed 신규' 체크박스 — 무조건 탐색 방지·중지 시 기존 seed 사용 (PRD v1.26, S4.13)

| id | 기대 |
|---|---|
| 44-1 | 'SEED 값 생성' 버튼 옆 'seed 신규' 체크박스, 기본 해제 |
| 44-2 | 해제 상태(기본)에서 '추천 생성'/'추천 생성(순차)' 클릭 → SEED 탐색 없이 현재 seed 값으로 즉시 생성 |
| 44-3 | 체크한 상태에서 클릭 → v1.24 와 동일하게 탐색을 (재)시작해 완료되는 즉시 그 seed 로 자동 생성 |
| 44-4 | SEED 탐색이 이미 완료돼 있으면 체크박스와 무관하게 즉시 생성(재탐색 없음) |
| 44-5 | 체크 상태로 대기 중 'SEED 생성 중지' 클릭 → 생성을 취소하지 않고 **탐색 시작 전 seed 값**으로 생성 |
| 44-6 | 탐색이 오류로 끝나면 예약된 생성은 안전하게 취소(생성하지 않음) |
| 44-7 | 회귀: vitest·tsc·eslint (백엔드 변경 없음), 라이브 화면 |
